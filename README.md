# 2-Digit 7-Segment Display Interfacing using STM32

## Overview

This project demonstrates interfacing two 7-segment displays with the STM32F446RE microcontroller.

The STM32 controls the two displays to show numerical values from 00 to 99.

The project uses multiplexing to efficiently control both 7-segment displays using shared segment pins and separate digit control pins.

---

## Components Used

- STM32F446RE Nucleo Board
- 2 × 7-Segment Displays
- Current Limiting Resistors
- Jumper Wires
- Breadboard

---

## Features

- Controls two 7-segment displays
- Displays numbers from 00 to 99
- Uses multiplexing technique
- Uses STM32 GPIO pins
- Controls tens and units digits
- Demonstrates GPIO output control
- Reduces the number of GPIO pins required

---

## Software Used

- STM32CubeIDE
- STM32CubeMX
- Proteus Professional
- C Programming Language
